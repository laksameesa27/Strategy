Module 2 · Asset Optimization (Cost Avoidance)

การเช่าเครื่องถ่ายเอกสารแบบกลุ่มบริษัท และการโยกย้ายเครื่องถ่ายเอกสารในเครือระหว่างสัญญา

รวมการเช่าทั้งองค์กรเป็น Group Deal จัดสรรผ่านทีม WMS แล้วโยกย้ายเครื่องที่ว่างไปยัง Site แทนการเช่าใหม่

1. Timeline การดำเนินงาน

ก่อน Group Deal

  1. แต่ละ BU เช่าเครื่องถ่ายเอกสารเองสัญญาและ Vendor แยกกันตามโครงการ
  2. จัดซื้อตรวจ Report พบราคาไม่เท่ากันค่าเช่าแต่ละ BU ต่างกัน
  3. ค่าปริ้นต่างกันด้วยVendor คิดตามปริมาณปริ้นต่อเดือน การคำนวณจึงไม่เท่ากัน

Bidding แบบ Group Deal

  1. รวมจำนวนเครื่องทั้งองค์กรจัดซื้อดึงข้อมูลจากทุก BU
  2. Bidding เป็น Group Dealใช้ปริมาณรวมต่อรองราคาเช่าและค่าปริ้น
  3. ออกระเบียบการเช่าทุกโครงการต้องผ่านทีม WMS และใช้เฉพาะรุ่นที่ Bidding

ระหว่างปี: โยกย้ายเครื่อง

  1. Site แจ้งความต้องการผ่าน WMSสัญญาเดิมหมดอายุหรือมี Site เกิดใหม่
  2. WMS จัดสรรเครื่องที่ว่างเครื่องที่ลดจากสำนักงานใหญ่ตามนโยบาย Paper rate
  3. ไม่เช่าเครื่องใหม่หลีกเลี่ยงค่าเช่า 6 เครื่อง 194,400 บาท/ปี

2. ที่มาของแผน

สัญญาเช่าตาม Site ทยอยหมดอายุ

บาง Site เกิดใหม่ และยังจำเป็นต้องมีเครื่องถ่ายเอกสารใช้งานต่อ

บริษัทรณรงค์ลดการใช้กระดาษ ความจำเป็นใช้เครื่องถ่ายเอกสารตามจุดจึงลดลง

Module 3 · License Co-termination Strategy (Microsoft O365)

รวมวันหมดอายุ License O365 ให้ตรงกัน เพื่อซื้อแบบ Volume

เปลี่ยนจากการซื้อแยกรายบริษัท ไปเป็นการซื้อรวมศูนย์ผ่าน IT และจัดซื้อ Bidding ครั้งเดียว

1. สถานการณ์ปัจจุบัน

ซื้อแยกรายบริษัท (60+ บริษัท)

User ขอกับ IT แล้ว IT เช็คเพียงว่าบริษัทนั้นไม่มี License เหลือ ก็ให้ซื้อใหม่

ซื้อครั้งละ 1 ปี

ทุกครั้งที่ซื้อเริ่มนับ 1 ปีใหม่ วันหมดอายุจึงกระจายและไม่พร้อมกัน

ต่อรองไม่ได้

Volume กระจายเป็นก้อนเล็ก จัดซื้อไม่มีอำนาจต่อรอง เสียโอกาสได้ราคาและเงื่อนไขที่ดี

IT บริหารยาก

ต้องติดตามการต่ออายุหลายวันตลอดปี ในหลายบริษัท

2. Timeline การดำเนินงาน

ก่อน Bidding

  1. IT วางแผนเดิม: ซื้อปีต่อปีปีละ ~2,666,667 บาท และราคา License ปรับขึ้นได้ทุกปี
  2. จัดซื้อเสนอสัญญา 3 ปี ยืนราคา USDกำหนดเป็นเงื่อนไขของการ Bidding
  3. ปรับ License ให้จบพร้อมกัน (Co-term)ปีแรกต่ออายุไปสิ้นสุดพร้อมสัญญาที่ยาวที่สุด
  4. IT รวบรวม Volume จากทุกบริษัท1,465 License งบ 3 ปี 8,000,000 บาท

Bidding

  1. จัดซื้อประมูลแบบรวม Volumeตามเงื่อนไข 3 ปี ยืนราคา USD และขอเครดิตเทอมยาวขึ้น
  2. ผลลัพธ์: 7,531,604.12 บาท (รวม 3 ปี)ประหยัด 468,395.88 บาท (5.85%)

หลัง Bidding

  1. โยกงบของแต่ละหน่วยงานมาที่ ITIT บริหารงบและปริมาณ License
  2. ต่ออายุครั้งเดียว ลดงาน PR/POทีมงานมีเวลาบริหารเรื่องอื่น

3. วันหมดอายุ ก่อนและหลัง

ภาพประกอบเชิงแนวคิด แสดงจำนวนสัญญาที่ครบกำหนดในแต่ละเดือน ไม่ใช่ข้อมูลจริง

ก่อน: กระจายทั้งปี

Module 5 · การบริหารจัดการซัพพลายเออร์ (Travel Management)

ใช้ TMC Hold ราคาตั๋วเครื่องบิน ลดการ Reject PR ซ้ำซ้อน

เปลี่ยนจากการจองเองผ่านเว็บทั่วไป เป็นทำสัญญากับ TMC (Travel Management Company) ที่ล็อกราคาไว้ชั่วคราวระหว่างรออนุมัติ

1. Timeline การดำเนินงาน

เตรียมการ (จัดซื้อ)

  1. ตั้งตุ๊กตาการเดินทางกำหนดวันเวลา สายการบิน ค่าประกันการเดินทาง และ Service Fee ทั้งในและต่างประเทศ
  2. ส่งข้อมูลให้ TMC เสนอราคาทุก Vendor ได้โจทย์เดียวกัน
  3. จัดซื้อเปรียบเทียบข้อเสนอดูแนวโน้มราคาและวิธีคิดค่าบริการของแต่ละ Vendor

กำหนดนโยบาย

  1. เสนอข้อมูลต่อผู้บริหารสรุปผลเปรียบเทียบ Vendor
  2. ออกนโยบายเช็คราคา 2–3 รายทุกครั้งที่จอง

ทุกครั้งที่จอง

  1. เลขาขอราคาจาก TMC 2–3 รายVendor Hold ราคาไว้ เช่น 24–72 ชั่วโมง
  2. เลือกราคาที่ดีที่สุด ทำ Memoเสนอผู้มีอำนาจลงนาม
  3. เปิด PR แล้วส่งภาพ PR ทางเมลแจ้ง Vendor ที่ได้งาน
  4. Vendor จองตั๋วและ Confirm กับ Userประมาณ 1–2 วัน
  5. PR ถึงจัดซื้อ แล้ว PO ตามมาไม่ต้อง Reject เพราะราคาขึ้น

2. ที่มาของแผน

PR/PO ใช้เวลา 2–3 วันทำการ

ระหว่างรออนุมัติ ราคาตั๋วเปลี่ยนได้ตลอด

ราคาปรับขึ้นก่อนถึงจัดซื้อ

จัดซื้อเช็คราคาแล้วพบว่าสูงขึ้น ต้อง Reject งานกลับ

ทุกหน่วยงานทำซ้ำ

ต้องเร่ง Process ใหม่หลายรอบ เสียเวลาผู้เกี่ยวข้องทุกฝ่าย

24–72 ชม.ระยะที่ TMC Hold ราคาได้ (ตัวอย่าง)
2–3 รายเช็คราคาต่อการจองแต่ละครั้ง
1–2 วันVendor Confirm ข้อมูลกับ User
2–3 วันกระบวนการ PR/PO เดิม

3. ประโยชน์ที่ได้รับ

ราคาไม่ขยับระหว่างอนุมัติ

Hold ราคาไว้ ทำให้มีเวลาตรวจตารางงานผู้บริหารและอนุมัติโดยไม่เสียราคาที่ดี

ลดงานซ้ำซ้อน

ลดการ Reject PR และการเร่ง Process รอบใหม่ของทุกหน่วยที่เกี่ยวข้อง

ราคาดีและตรวจสอบได้

เทียบ 2–3 ราย เลือกราคาที่ดีที่สุด พร้อม Memo อนุมัติเป็นหลักฐาน

ระยะเวลา Hold จริงขึ้นกับเงื่อนไขของแต่ละ Vendor และสายการบิน ตัวเลข 24–72 ชั่วโมงเป็นตัวอย่าง
